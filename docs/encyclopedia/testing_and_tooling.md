# Testing and Tooling

This document summarizes the project's testing strategy (unit vs E2E), the available test scripts, and the primary tooling used to run, lint and build the project.

## High-level testing strategy

- Unit tests
  - Framework: Vitest (configured in vitest.config.ts)
  - Environment: happy-dom (DOM emulation for Preact components)
  - Test locations: src/**/*.test.{ts,tsx} and tests/unit/**/*.test.{ts,tsx}
  - Setup: tests/setup.ts is executed before tests
  - Coverage: V8 provider; coverage config lives in vitest.config.ts and excludes tests/** and test files themselves

- End-to-end (E2E) tests
  - Framework: Playwright (@playwright/test)
  - Test directory: tests/e2e
  - Configuration: playwright.config.ts (configures baseURL, webServer, timeouts, video/trace settings and projects)
  - Playwright webServer: runs vite via `pnpm exec vite --host <HOST> --port <PORT> --strictPort` so E2E runs against an instrumented dev server
  - Useful env vars: PLAYWRIGHT_PORT, PLAYWRIGHT_HOST, PLAYWRIGHT_BASE_URL, DEMO_MODE (used by some e2e demo scripts)

## Available npm/pnpm scripts (from package.json)
- dev: vite (run dev server)
- build: vite build
- build:typecheck: tsc && vite build
- preview: vite preview
- typecheck: tsc --noEmit
- lint: eslint src --ext .ts,.tsx

Testing scripts
- test: vitest run (unit tests)
- test:watch: vitest (interactive watch mode)
- test:coverage: vitest run --coverage
- test:e2e: playwright test (run all Playwright tests)
- test:e2e:headed: playwright test --headed
- test:e2e:ui: playwright test --ui
- test:e2e:journey: playwright test tests/e2e/gameplay-journey.spec.ts
- test:e2e:demo: DEMO_MODE=true playwright test --headed tests/e2e/gameplay-demo.spec.ts
- test:e2e:demo:ui: DEMO_MODE=true playwright test --ui tests/e2e/gameplay-demo.spec.ts
- test:all: pnpm test && pnpm test:e2e
- test:e2e:tower: playwright test --headed tests/e2e/gameplay-full-tower.spec.ts
- test:e2e:tower:demo: DEMO_MODE=true playwright test --headed tests/e2e/gameplay-full-tower.spec.ts

## Tooling and developer workflow
- Package manager: pnpm (repository uses pnpm in scripts; run scripts with `pnpm <script>`)
- Bundler/dev server: Vite (vite, vite build, vite preview)
- Type system: TypeScript (tsconfig.json present; `pnpm typecheck` runs tsc)
- Linting: ESLint (configured via package.json script `lint`)
- Unit testing: Vitest (happy-dom environment; run via `pnpm test`)
- E2E testing: Playwright (run via `pnpm test:e2e`)

## File layout notes
- Unit tests: colocated in src as `*.test.ts(x)` and in tests/unit
- E2E tests: tests/e2e
- Test setup: tests/setup.ts for global setup used by unit tests

## Recommendations / Observations
- CI friendliness: Playwright config reads PLAYWRIGHT_PORT/PLAYWRIGHT_HOST and sets retries when CI env is present; ensure CI sets these sensibly.
- Local debug: use `pnpm test:watch` for iterative unit testing and `pnpm test:e2e:headed` for debugging Playwright flows.
- Coverage: vitest uses v8 coverage provider with JSON/HTML output in coverage artifacts; use `pnpm test:coverage` to generate reports.

---

## How to run (local)

- Install dependencies: `pnpm install`
- Run unit tests once: `pnpm test`
- Run unit tests in watch mode: `pnpm test:watch`
- Generate unit coverage: `pnpm test:coverage`
- Run E2E tests (Playwright; starts Vite dev server automatically): `pnpm test:e2e`
- Run a headed/demo E2E session: `pnpm test:e2e:demo` or `pnpm test:e2e:headed`
