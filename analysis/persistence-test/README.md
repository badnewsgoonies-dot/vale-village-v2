analysis/persistence-test/README.md

Purpose
-------
This directory contains a small persistence test script and artifact used by automation to validate that the runner can create and persist files.

Files
-----
- creation.sh: executable POSIX shell script which writes persist_marker.txt containing the token 'VV2-PERSISTENCE-TEST' and an ISO8601 UTC timestamp.
- persist_marker.txt: generated by running creation.sh; contains token and timestamp.
- .gitkeep: empty file to ensure the directory is present in version control.

Usage
-----
Run ./creation.sh from this directory (or /analysis/persistence-test/creation.sh from repo root) to create the marker file.
